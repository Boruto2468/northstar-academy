# Northstar Academy
Year 10 (British curriculum, 2026/27 Term 1) Maths and Biology practice platform.

## Run
`npm install && npm run dev`

## GitHub Pages
Create a repository named `northstar-academy`, push to `main`, then select **GitHub Actions** as the Pages source in Settings → Pages. The workflow builds a static Next.js export.

## Add a topic
Add a typed topic record to `src/data/topics.ts` (or import it from a separate data module). Routes are automatically generated from the registry.

## Current limitations
This is an initial runnable foundation, not a finished curriculum release. The topic coverage is scaffolded and requires fuller handwritten question banks, exact-form validation tests, richer diagrams, drag-to-label games, true 3D fallback, eight distinct celebration designs, spaced-review scheduling, and fully generated worked examples before production use.
